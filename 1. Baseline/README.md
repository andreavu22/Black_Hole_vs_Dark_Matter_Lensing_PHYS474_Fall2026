The file `j9op14ohq_flt.fits` was obtained from the Mikulski Archive for Space Telescopes (MAST). It was used to extract instrumental parameters such as exposure time, read noise, and detector gain. Due to its large size, the FITS file is not included in this repository. It can be downloaded from MAST if needed. The lensing simulations use the extracted instrumental parameters and do not require the original FITS image.
